# Generated Website

## AI Write Scope

AI changes are limited to:

- `src/**`
- `public/**`

## Read-Only Files

- `package.json`
- `pnpm-lock.yaml`
- `scripts/**`
- `config/**`
- `wrangler.jsonc`
- Vite, TypeScript, lint, and test configuration

## Validation

```bash
pnpm lint
pnpm typecheck
pnpm build
```
